# Adaptive-Walk-and-Epistasis-under-Fisher-Geometric-model
Simulation and analytical code for epistasis, contingency, and entrenchment in Fisher's geometric model

This repository contains the Python code used for simulations, numerical calculations, and figure generation in the manuscript:

**Maillard A., Maillard A., Coeuille I., and Tenaillon O**.
*From Diminishing Returns to Entrenchment: A Unifying Theory of Epistasis along Adaptive Walks Revealed by Fisher's Geometric Model.*

## Code

The Jupyter notebook Figures_Maillard2026.ipynb contains the code used to investigate epistasis along adaptive walks in Fisher's geometric model, including mutation sampling, pairwise epistasis, contingency, entrenchment, and mutation–selection–drift equilibrium.

## Usage

Open and run Figures_Maillard2026.ipynb in a Python environment with the required scientific libraries installed.
